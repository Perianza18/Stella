# Stella

Stella is an astronaut otter who loses her favorite rock in a space anomaly and sets off across 6 levels to find it. Each level is a narrative wrapper around a different logic / game-theory puzzle.

## Project structure

- `Level Design/` — level design docs (story, rules, strategy). Start at `00 - Story & Level Index.md`.
- `Levels/` — code for each level, one folder per level (`Level 1` … `Level 6`), each with a `README.md` pointing to its design doc.
