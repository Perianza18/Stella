# Stella

## Estructura del proyecto

- `Propuesta de Niveles/` — diseño de cada nivel (historia, reglas, estrategia). Empieza por `00 - Historia Base e Indice.md`.
- `Levels/` — código de cada nivel, una carpeta por nivel (`Level 1` … `Level 6`), con un `README.md` que apunta al diseño correspondiente.
