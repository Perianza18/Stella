# Stella

Stella is an astronaut otter who loses her favorite rock in a space anomaly and sets off across 6 levels to find it. Each level is a narrative wrapper around a different logic / game-theory puzzle. Change

## Project structure

- [`docs/`](docs/README.md) — project documentation and game-design material. Start with the [story and level index](docs/game-design/story-and-level-index.md).
- [`prototypes/python/`](prototypes/python/README.md) — Python console prototypes, organized into one folder per level.
- `stella_unity/` — location reserved for Stella's Unity content. The Unity project has not been created yet.
