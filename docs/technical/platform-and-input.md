# Platform and Input

## Presentation

Stella uses true 2D presentation and pixel art. Puzzles appear as close-up, first-person-style interfaces: each scene should feel like a self-contained task panel. Visible hands are not required.

## Pointer Interaction

Design interactions around a platform-neutral **pointer**, not around a mouse specifically:

- Desktop and browser: click.
- Mobile: tap.

Avoid drag-and-drop unless a puzzle genuinely requires it. Essential interactions must not depend on hover, right click, or keyboard-only controls. Touch targets must be large enough for comfortable mobile use.

## Target Platforms

The target platforms are browser and mobile. Exact packaging and deployment choices will be made during Unity setup.
